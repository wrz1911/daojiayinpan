## 1. 基础约定

### 1.1 十二状态（顺序固定）

```
长生 → 沐浴 → 冠带 → 临官 → 帝旺 → 衰 → 病 → 死 → 墓 → 绝 → 胎 → 养
```

阳干顺行、阴干逆行（各干长生起点不同，见 §2.1）。

### 1.2 宫位与地支

| 宫 | 卦 | 地支 | 备注 |
|---|---|---|---|
| 1 | 坎 | 子 | 单支 |
| 2 | 坤 | 未、申 | 双支 |
| 3 | 震 | 卯 | 单支 |
| 4 | 巽 | 辰、巳 | 双支 |
| 5 | 中 | — | **不显示长生**（奇门中宫不列） |
| 6 | 乾 | 戌、亥 | 双支 |
| 7 | 兑 | 酉 | 单支 |
| 8 | 艮 | 丑、寅 | 双支 |
| 9 | 离 | 午 | 单支 |

双支宫位的两个状态按「地支顺序」拼接，例如宫 2（未、申）显示「墓绝」。

## 3. 逻辑

### 3.1 取干

对每个宫位（1–9，跳过 5）：

```
天盘干 = palaces[宫].tian 的首字符
地盘干 = palaces[宫].di   的首字符
```

奇门的天盘/地盘干只可能是六仪三奇（戊己庚辛壬癸丁丙乙），不会出现甲。

> 若你的盘面把「中宫寄干」拼进坤 2（如 `乙癸`），首字符仍是本干，寄干状态**不显示**。

### 3.2 查表

```
状态 = TABLE[天盘干][宫号]
```

直接按宫号查 §2.2 即可，**不需要**地支/起点/顺逆的计算。

### 3.3 显示

- 每个宫位有两个槽位：`stateTian{宫}`（天盘干状态）、`stateDi{宫}`（地盘干状态）
- 开关切换时填充/清空，不影响盘面其他内容
- 中宫（5）不显示

### 3.4 本项目实现细节（仅当你要复刻本项目的数据结构）

本项目的表按 `[宫4, 宫9, 宫2, 宫3, 宫7, 宫8, 宫1, 宫6]` 顺序存为 8 元素数组：

```js
CS_IDX = { 4: 0, 9: 1, 2: 2, 3: 3, 7: 4, 8: 5, 1: 6, 6: 7 };
状态 = CHANGSHENG[干][CS_IDX[宫号]];
```

如果你不需要复刻，用 §2.2 的宫号直接查更直观。

## 4. 参考实现（JavaScript）

```js
const TABLE = {
  '乙': { 1:'病',  2:'胎养', 3:'临', 4:'沐冠', 6:'死墓', 7:'绝', 8:'旺衰', 9:'生' },
  '丙': { 1:'胎',  2:'衰病', 3:'沐', 4:'冠临', 6:'墓绝', 7:'死', 8:'养生', 9:'旺' },
  '丁': { 1:'绝',  2:'沐冠', 3:'病', 4:'旺衰', 6:'胎养', 7:'生', 8:'死墓', 9:'临' },
  '戊': { 1:'胎',  2:'衰病', 3:'沐', 4:'冠临', 6:'墓绝', 7:'死', 8:'养生', 9:'旺' },
  '己': { 1:'绝',  2:'沐冠', 3:'病', 4:'旺衰', 6:'胎养', 7:'生', 8:'死墓', 9:'临' },
  '庚': { 1:'死',  2:'冠临', 3:'胎', 4:'养生', 6:'衰病', 7:'旺', 8:'墓绝', 9:'沐' },
  '辛': { 1:'生',  2:'旺衰', 3:'绝', 4:'死墓', 6:'沐冠', 7:'临', 8:'胎养', 9:'病' },
  '壬': { 1:'旺',  2:'养生', 3:'死', 4:'墓绝', 6:'冠临', 7:'沐', 8:'衰病', 9:'胎' },
  '癸': { 1:'临',  2:'死墓', 3:'生', 4:'胎养', 6:'旺衰', 7:'病', 8:'沐冠', 9:'绝' },
  // 甲：第三方无此行；如需 10 干，按阳干顺行补：
  '甲': { 1:'沐浴', 2:'墓绝', 3:'帝旺', 4:'衰病', 6:'养长', 7:'胎', 8:'临冠', 9:'死' },
};

/** 取某宫的天/地盘干长生状态；返回 null 表示该宫不显示 */
function changsheng(palaces, gong) {
  if (gong === 5) return null;
  const p = palaces[gong];
  if (!p) return null;
  const tian = p.tian ? p.tian[0] : '';
  const di = p.di ? p.di[0] : '';
  return {
    tian: TABLE[tian] ? TABLE[tian][gong] : '',
    di: TABLE[di] ? TABLE[di][gong] : '',
  };
}
```
